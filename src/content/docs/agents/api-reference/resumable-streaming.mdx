The Agents SDK provides a `ResumableStreamManager` for implementing AI streaming that automatically resumes after disconnections or page refreshes, and supports streaming to multiple clients simultaneously.

## Overview

The `ResumableStreamManager` handles the complexity of reliable streaming in production environments:

* Chunk persistence in SQLite for replay after disconnections
* Stream metadata tracking (streaming, completed, error states)
* Complete message history with timestamps
* Automatic detection and replay of active streams
* Multi-client support with real-time updates via WebSockets

This allows you to build AI streaming applications that work reliably even when users refresh their browser, switch tabs, or experience network interruptions.

## Setup

Instantiate the manager in your Agent class by passing the Agent instance and context:

<TypeScriptExample>

```ts
import { Agent, ResumableStreamManager } from "agents";

export class ChatAgent extends Agent<Env, State> {
  // Initialize the manager with the agent instance and context
  private streams = new ResumableStreamManager(this, this.ctx);

  // ... rest of implementation
}
```

</TypeScriptExample>

## Required implementation

Your Agent must implement two methods to work with the `ResumableStreamManager`:

### generateAIResponse()

This method receives options from the manager and must:

1. Generate an AI response using any AI SDK
2. Call `processChunk()` for each chunk (handles saving and broadcasting)
3. Return the complete content

<TypeScriptExample>

```ts
async generateAIResponse(options: GenerateAIResponseOptions): Promise<string> {
  const messages = options.messages.map((msg) => ({
    role: msg.role,
    content: msg.content
  }));

  const result = streamText({
    model: openai("gpt-4o"),
    messages
  });

  let fullContent = "";
  // Stream and broadcast each chunk
  for await (const chunk of result.textStream) {
    fullContent += chunk;
    await options.processChunk(chunk);
  }

  return fullContent;
}
```

</TypeScriptExample>

### \_handleStreamGeneration()

This is a queue callback that delegates to the manager. It processes AI generation in the background:

<TypeScriptExample>

```ts
async _handleStreamGeneration(
  payload: { userMessageId: string; streamId: string },
  _queueItem?: QueueItem
) {
  await this.streams.generateResponseCallback(payload);
}
```

</TypeScriptExample>

## Core types

### ResumableMessage

Represents a message in the conversation history:

<TypeScriptExample>

```ts
export type ResumableMessage = {
  id: string;
  role: "user" | "assistant";
  content: string;
  createdAt: number;
};
```

</TypeScriptExample>

### ResumableStreamChunk

Represents an individual chunk of a streaming response:

<TypeScriptExample>

```ts
export type ResumableStreamChunk = {
  id: string;
  streamId: string;
  content: string;
  index: number;
  createdAt: number;
};
```

</TypeScriptExample>

### ResumableStreamMetadata

Contains metadata about a stream's status and progress:

<TypeScriptExample>

```ts
export type ResumableStreamMetadata = {
  id: string;
  messageId: string;
  status: "streaming" | "completed" | "error";
  totalChunks: number;
  createdAt: number;
  completedAt?: number;
  error?: string;
};
```

</TypeScriptExample>

### GenerateAIResponseOptions

Options passed to the `generateAIResponse()` method:

<TypeScriptExample>

```ts
export type GenerateAIResponseOptions = {
  messages: ResumableMessage[];
  streamId: string;
  messageId: string;
  processChunk: (content: string, index?: number) => Promise<void>;
};
```

</TypeScriptExample>

### ResumableStreamState

The state interface your Agent should extend to use resumable streaming:

<TypeScriptExample>

```ts
export interface ResumableStreamState {
  messages: ResumableMessage[];
  activeStreamId: string | null;
  [key: string]: unknown; // Extend with custom properties
}
```

</TypeScriptExample>

### ResumableStreamAgent

The interface defining the contract for Agents using resumable streaming:

<TypeScriptExample>

```ts
export interface ResumableStreamAgent<
  Env = unknown,
  State extends ResumableStreamState = ResumableStreamState
> extends Agent<Env, State> {
  generateAIResponse(options: GenerateAIResponseOptions): Promise<string>;
  _handleStreamGeneration(
    payload: { userMessageId: string; streamId: string },
    queueItem?: QueueItem
  ): Promise<void>;
}
```

</TypeScriptExample>

## Core methods

### initializeTables()

Creates SQLite tables for message and stream persistence. Call this during your Agent's `onStart()` method:

<TypeScriptExample>

```ts
async onStart() {
  await super.onStart();
  await this.streams.initializeTables();
}
```

</TypeScriptExample>

**Tables created:**

* `messages` - conversation history
* `stream_chunks` - individual chunks for each stream
* `stream_metadata` - stream status and metadata

### sendMessage()

Saves a user message and queues AI response generation. This method returns immediately while AI generation happens in the background via the queue system:

<TypeScriptExample>

```ts
const { messageId, streamId } = await this.streams.sendMessage("Hello!");
```

</TypeScriptExample>

**Parameters:**

* `content` - the user's message text

**Returns:** Object containing `messageId` and `streamId`

### loadMessages()

Loads all messages from storage, ordered by creation time:

<TypeScriptExample>

```ts
const messages = await this.streams.loadMessages();
console.log(`Loaded ${messages.length} messages`);
```

</TypeScriptExample>

### loadAndSyncMessages()

Loads messages from storage and syncs them to Agent state. Call this during `onStart()` to restore conversation history:

<TypeScriptExample>

```ts
async onStart() {
  await super.onStart();
  await this.streams.initializeTables();
  await this.streams.loadAndSyncMessages();
}
```

</TypeScriptExample>

### getStreamHistory()

Retrieves stream chunks and metadata for resuming after a disconnection:

<TypeScriptExample>

```ts
const { chunks, metadata } = await this.streams.getStreamHistory(streamId);

if (metadata?.status === "streaming") {
  const content = chunks
    .sort((a, b) => a.index - b.index)
    .map((c) => c.content)
    .join("");
  console.log("Replaying:", content);
}
```

</TypeScriptExample>

**Parameters:**

* `streamId` - ID of the stream to retrieve

**Returns:** Object containing `chunks` array and `metadata` object (or null)

### clearHistory()

Removes all messages, chunks, and metadata from storage:

<TypeScriptExample>

```ts
await this.streams.clearHistory();
this.setState(this.initialState);
```

</TypeScriptExample>

:::note

This only clears storage. You must also reset Agent state separately.

:::

### cleanupOldStreams()

Clean up old completed stream chunks to prevent storage growth. Defaults to removing streams older than 7 days:

<TypeScriptExample>

```ts
// Clean up streams older than 7 days
await this.streams.cleanupOldStreams();

// Or specify a custom retention period (in milliseconds)
await this.streams.cleanupOldStreams(24 * 60 * 60 * 1000); // 1 day
```

</TypeScriptExample>

**Parameters:**

* `olderThanMs` - Remove chunks from streams completed longer than this (in milliseconds). Defaults to 7 days (604800000ms).

**Returns:** Number of streams cleaned up

## How it works

### Message flow

1. User sends a message via `sendMessage()`
2. Message is saved to SQLite and state is updated (5-10ms)
3. `_handleStreamGeneration` is queued for background processing
4. AI generation happens asynchronously
5. Each chunk is saved and broadcast in real-time
6. Complete message is saved when the stream finishes

### Resume flow

**On reconnect:**

1. Client receives state update with `activeStreamId`
2. Client calls `getStreamHistory()` to fetch chunks
3. Client reconstructs streaming message from chunks

**Multi-tab support:**

* All tabs receive real-time chunks via WebSocket
* New tabs detect active stream from state
* Deduplication prevents double-replay

### Storage architecture

The manager uses a dual-layer storage pattern:

* **SQLite tables** - for queries, pagination, and search
* **Agent state** - for automatic client synchronization via WebSockets

## Complete example

The following example demonstrates a complete implementation of a resumable streaming chat Agent:

<TypeScriptExample>

```ts
import { openai } from "@ai-sdk/openai";
import {
  Agent,
  callable,
  ResumableStreamManager,
  type GenerateAIResponseOptions,
  type QueueItem,
  type ResumableStreamState
} from "agents";
import { streamText } from "ai";

type Env = {
  OPENAI_API_KEY: string;
};

export interface ChatState extends ResumableStreamState {
  // Inherits: messages, activeStreamId
}

export class ResumableStreamingChat extends Agent<Env, ChatState> {
  private streams = new ResumableStreamManager(this, this.ctx);

  initialState: ChatState = {
    messages: [],
    activeStreamId: null
  };

  async onStart() {
    await super.onStart();
    await this.streams.initializeTables();
    await this.streams.loadAndSyncMessages();
  }

  @callable()
  async sendMessage(
    content: string
  ): Promise<{ messageId: string; streamId: string }> {
    return this.streams.sendMessage(content);
  }

  async generateAIResponse(
    options: GenerateAIResponseOptions
  ): Promise<string> {
    const messages = options.messages.map((msg) => ({
      role: msg.role,
      content: msg.content
    }));

    const result = streamText({
      model: openai("gpt-4o"),
      messages
    });

    let fullContent = "";
    for await (const chunk of result.textStream) {
      fullContent += chunk;
      await options.processChunk(chunk);
    }

    return fullContent;
  }

  async _handleStreamGeneration(
    payload: { userMessageId: string; streamId: string },
    _queueItem?: QueueItem
  ) {
    await this.streams.generateResponseCallback(payload);
  }

  @callable()
  async getStreamHistory(streamId: string) {
    return this.streams.getStreamHistory(streamId);
  }

  @callable()
  async clearHistory() {
    await this.streams.clearHistory();
    this.setState(this.initialState);
  }
}
```

</TypeScriptExample>
